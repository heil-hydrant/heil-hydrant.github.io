## Project Summary

This project ports the [Hugo Minimal Black](https://gitlab.com/jimchr12/hugo-minimal-black) theme to Zola, converting Go HTML templates into Tera v2 templates and components while preserving all CSS custom properties, card hover animations, the floating macOS-inspired action dock, and `Ctrl+K` instant search.
